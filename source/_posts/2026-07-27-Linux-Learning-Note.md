## Lesson 0：系统的认知

按照传统~~(狗屎)~~的教学方式，老师会打开百度百科搜索 Linux 词条：

> Linux，一般指 GNU/Linux（单独的 Linux 内核并不可直接使用，一般搭配 GNU 套件，故得此称呼），是一种免费使用和自由传播的类 UNIX 操作系统，其内核由林纳斯·本纳第克特·托瓦兹（Linus Benedict Torvalds）于 1991 年 10 月 5 日首次发布，它主要受到 Minix 和 Unix 思想的启发，是一个基于 POSIX 的多用户、多任务、支持多线程和多 CPU 的操作系统。它支持 32 位和 64 位硬件，能运行主要的 Unix 工具软件、应用程序和网络协议。

讲到最后也不知道是在讲什么玩意，学生只会觉得：**Linux 怎么还有这么多东西，这么多特点、这么多版本**。

就和国内教编程语言一样，计算机科班学的是 C 语言或者 C++，非计算机类可能学的是 Python，对于一个从没接触过其他编程语言和设计模式的学生大谈这个语言有什么特性。如：

> C 语言是一种面向过程的计算机编程语言，属于高级语言。
>
> Python 由荷兰国家数学与计算机科学研究中心的吉多·范罗苏姆于 1990 年代初设计，作为 ABC 语言的替代品，是一种解释型脚本语言。

一上来就灌输各种高深的专业名词，学生不会觉得你讲的好好，只会在想什么是解释型语言？什么是编译型语言？什么是 OOP？什么是 POP？纯粹的概念灌输一点用都没有。

### 系统的概念

大家常用的应该是 Windows 10 / Windows 11。

**系统**：鼠标能点、键盘能输入东西、阅读、看电影，可拓展、安装软件等，通过键盘/鼠标进行人机交互。比如我现在在写下的这篇笔记，就是用 VSCode 写的，那么，VSCode 就是运行在 Microsoft Windows 11 这个系统里面的。

如果光有硬件没有系统或者系统出错，那么电脑开机只会看到 BIOS 的黑框框（NO Media），什么都干不了。

> 开机看到的东西就是系统。
